BYU–Hawaii (demo host page)

This page simulates a BYU–Hawaii website. The chat bubble is bottom-right.

How to embed

Add a single line before </body> on any BYU–Hawaii page:

<script src="https://YOUR-BOT-DOMAIN/embed.js" defer></script>

Optional attributes: data-position="left", data-color="#002e5d", data-greeting="Need help?".

This demo loads embed.js from the same origin it is served from, so it works against local dev and any deployed environment without edits.
